# AdmitConnect – Counselling Call Tracker (Demo)

Clickable demo of an admission-counselling platform: bot calls (IVR), WhatsApp/SMS follow-ups,
admissions with proof, and college seat dashboards.

**Live site:** https://karthikeyasm.github.io/admitconnect/

- Single self-contained page (`index.html`), works offline too.
- All names, phone numbers, colleges and figures are **mock data**.
